# Kitchen Service

## Overview

The **Kitchen Service** is a web-based application designed to optimize kitchen operations. It helps kitchen staff manage dishes, track ingredients, monitor chefs' work, and ensure smooth operation in a restaurant environment. This system dish preparation, and efficient inventory management.

## Features

- **Dish Management**: Track and manage dishes, including their ingredients, types, and images.
- **Cook Management**: Assign and manage chefs' tasks and track their years of experience.
- **Ingredient Management**: Manage available ingredients and link them to different dishes.
- **Real-time Updates**: The system updates in real-time, ensuring that all users have the latest information.


## Technologies Used

- **Frontend**: HTML, CSS, JavaScript (React)
- **Backend**: Django (Python)
- **Database**: SQLite
- **Authentication**: Django's built-in authentication (AbstractUser)
